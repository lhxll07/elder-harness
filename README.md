# 银龄智办——可信跨应用助老智能体

> **“老人说出需求，智能体跨应用协助办理，关键操作交还本人，遇到困难衔接可信的人。”**

「银龄智办」（开发代号：`elder-harness`，原名「银龄专线」）是一款专为老年人设计的 **Android 跨应用手机办事智能体原型**。老人无需在复杂的手机界面中摸索寻找，只需像平时说话一样说清想法，助手便能跨应用协助查车票、看快递、调字号、填消息；遇到支付和敏感决定，规矩地交回老人自己把关；遇到卡点，平滑呼叫可信的亲友与社区接力。

大模型规划与语音识别依托成熟云端能力，**本项目的核心自研贡献在于：可靠的手机执行框架、严谨的结果证据核验、懂分寸的适老安全协作机制，以及可验证的技能自进化体系**。

---

## 解决什么问题？

现在的智能手机功能繁多，但对许多长辈来说却像一座迷宫：
- **看不清、找不着**：字小图标密、入口藏在三级菜单里；
- **怕点错、怕扣费**：一不留神点中弹窗广告，甚至遭遇财产风险；
- **儿女不在身边，有心无力**：电话里教半天“点右上角那个小齿轮”，老人还是不知道在哪。

通用手机 Agent 虽然能代操作，但往往存在三大硬伤：**容易“吹牛交差”**（没办成却自称办好）、**容易“擅自越权”**（误替老人支付扣款）、**容易“死板僵化”**（App 一改版就失效）。

「银龄智办」正是为攻克这些痛点而生——**给老人配一个手脚勤快、心中有数、绝不越权的数字陪办员。**

## 四大核心创新机制（比赛与技术亮点）

为了让助老助手既能把事办好，又让老人和子女彻底放心，项目确立了四项关键机制：

| 机制 | 解决的痛点 | 核心思路（通俗说） | 研发状态 |
|---|---|---|---|
| **1. 办成有证据**<br>（任务证据核验） | 大模型常有“幻觉”，页面明明卡死或报错，却张口说“已为您办好”，误导老人 | **不说瞎话，办没办成拿证据说话**。<br>立下三道严密逻辑铁门，并结合操作前后截图对比。支持正文与收件人解耦核验；证据充足才算办成，证据不足宁可承认“无法确认”，绝不欺瞒。 | 手机端**强制先跑本机机械层与证据层**（文字来源/时间锚点/动作影响/事实来源），通过后才允许模型复核；执行者自己输入的文字不计入证据。前后截图视觉对比核验拟深入研发 |
| **2. 帮忙有分寸**<br>（分级自主执行） | 全自动操作容易误付误删；而每点一步都要老人确认，老人又嫌麻烦 | **替老人省手脚，绝不替老人做主**。<br>普通查看直接办；拿不准的操作只确认一次；支付、下单、发验证码等敏感红线坚决停手，“交还本人”亲手按。增强 10%+5% 双层坐标网格与真实 bounds 坐标校准。 | 原型已支持规则风控、坐标量化校准与本人交接；全路径统一风控推进中 |
| **3. 家人教一次**<br>（语义技能学习） | 传统脚本按固定屏幕坐标点击，App 一旦更新或有弹窗就点偏点错 | **学的是办事套路，不是死记硬背屏幕坐标**。<br>家人带着操作一遍，系统提炼通用的操作意图与页面条件；内置查表格、盲页、微信输入 3 条核心高频技巧，报错换路融入通用提示词，动态定位微调界面依然找得准。 | 原型已实现 3 条核心人工技巧按需加载；示范自动提取与迁移拟研发 |
| **4. 越用越会办**<br>（验证驱动的技能自进化） | 偶发网络抖动被误学成错误经验；或者修好了一个功能，却把其他常用功能改坏了 | **吃一堑长一智，新套路连过三关才上线，退步随时回退**。<br>办事卡点时复盘归因，提出改进候选方案；必须经受脱敏快照、界面换版、老任务防退化三项检验才启用；一旦不理想随时回滚。 | 原型已实现成功经验总结与家人手动采纳；自动选版与回放拟研发 |

### 技能自进化闭环（拟研发路径）

“家人教一次”解决了新技能的初次录入，“越用越会办”则让技能在日常使用中越来越聪明、越用越稳健：

```text
 遇到卡点/纠正 ───> 失败复盘归因 ───> 提炼候选新技能 ───> 三关严格验证 ───> 按版本安全启用
                                                             │                  │
                                                    (脱敏回放/换版/旧任务防退化)   └─若效果退化──> 一键安全回滚
```

1. **以客观证据积累经验**：真实记录操作目标与页面反馈，将核验成功的路径与失败卡点分开；绝不把模型的“自称完成”当成成功样本。
2. **从卡点提炼改进方案**：分清是入口找不到、页面新改版，还是临时网络卡顿；提炼出“先去订单页、再查物流”这种带条件的通用步骤，而非僵化的死坐标。
3. **验证通过才能转正**：新技能必须在脱敏快照上回放、在不同界面布局下测试、在以往老任务上做防退化回归。只有不破坏安全红线且完成率提高，才升级启用。
4. **安全底线与一键回退**：遇到界面完全不认识时，果断退回通用规划或求助真人；一旦发现新版技能出现误操作或效果退化，立刻自动退回上一稳定版本。任何自进化都绝不修改核心安全边界与模型底层权重。

## 交互体验：像跟真人打电话一样轻松

老人使用手机不需要学说明书，交互做到极致纯粹：

### 1. 一屏一件事，极简防误触
- 首页中央只有一个**大圆形按钮**，上面一行状态，下面一行提示。
- **圆钮的颜色就是直观的状态信号**：
  - 🟢 **绿色**：空闲待命，随时可以说话；
  - 🟠 **橙色**：麦克风开启，正在倾听老人的心声。
- 只有需要老人亲自确认或做决定时，才会弹出清晰的大字卡片；设置选项藏在右上角齿轮里，避免老人误触迷失。

### 2. 像真人打电话，不像死板对讲机
- **点一下就聊**：说完一句话自动识别并开始帮办，**不用一直按着按键，也不用说完再点一下**；
- **随时插话打断（Barge-in）**：助手正在念叨时，长辈突然想补充一句，只要开口，**助手立刻闭嘴**，无缝转为聆听状态；
- **有问有答超省心**：老人想追问补充，麦克风窗口保持等待（20 秒无声自动关麦防漏听）；
- **每一步都大声念出来**：“正在打开微信”、“正在查找火车票”，全过程透明，老人不会看着白屏犯嘀咕；
- **跨应用贴身悬浮台**：跳转到第三方 App 后，悬浮小胶囊始终陪伴在侧，显示“正在办第几步”，点开就能随时打断或叫停。

### 3. 实打实的落地工程填坑（ColorOS 真机验证）
- **攻克系统缺失识别 API**：部分国产定制系统（如 ColorOS）未向第三方应用开放原生语音识别服务。我们自建了轻量服务端听写代理（讯飞语音转写），手机端只负责轻量录放音，密钥安全存放在服务端，手机丢失也不泄露凭据；
- **化解 Android 11+ 包可见性暗坑**：声明了 `<queries>` 中的 `TTS_SERVICE`，解决了系统语音合成引擎被隐蔽屏蔽、导致“哑巴无法发声”的行业通病；
- **剪贴板隐私随用随清**：输入法候选栏输入所使用的剪贴板通道，在文本粘贴完成后立即主动清理，绝不在系统剪贴板残留老人隐私；
- **安全密钥与令牌版本联动**：`SecretStore` 加密版本号与 `ServerClient` 内存 token 缓存联动失效，避免配对重置时继续读取旧脏凭据；
- **滑块控件全兼容**：识别 `AbsSeekBar` 等扩展滑动条，确保系统设置调大字号等场景在少控件页面也能准确识别并平稳调节。

## 安全分寸：什么情况会停下来？

助手时刻恪守“帮忙不添乱、省力不越权”的底线：

| 场景 | 助手的行动 | 老人看到和感受到的 |
|---|---|---|
| **普通查阅与日常跳转**<br>（点击、滚动、翻页、打开应用…） | 助手直接代办，快速连贯完成 | 悬浮条语音播报进度，无需老人费心操作 |
| **无障碍盲区坐标点击**<br>（如微信聊天、部分银行类自绘界面） | 系统在每个任务中**仅确认一次**，获得同意后继续 | 弹出温和提示，询问是否允许辅助点按，不反复打扰 |
| **付款、结算、转账、密码、验证码、重要发送** | **硬性拦截，绝对不碰！**<br>助手将手机**交还本人** | 明确语音播报：“**这一步请您亲自操作**”，把金额、收件地址、点哪个按键说得明明白白。老人做完点“好了继续” |
| **做不到的事情**<br>（如无权操作、无对应功能） | 诚实判定并主动停止，绝不胡乱尝试 | 明确告知：“这件事在手机上办不到”，并解释具体原因 |
| **需要家人帮忙 / 遇到卡点** | 一键将上下文交接给亲友网页端 | 提示“已帮您联系家人”，老人耐心等待即可 |
| **老人想随时叫停** | 悬浮窗上时刻保留醒目的**“停下来”**按键 | 随时随地，老人一触即可完全中止任务 |

## 可信圈子：身边的家人与社区

老人遇到困难，不该陷入孤立无援的窘境。系统支持与亲友、社区绑定形成**低门槛守护圈**：

- **家人免装 App**：家人只需在电脑或手机浏览器打开网页，输入配对码即可连接；老人手机端也无需繁琐配置。
- **遇到卡点一键求助**：当任务遇到死胡同，老人一键将求助卡（附带目标与当前卡点）送达家人网页，家人在网页上点击“我来处理”即可认领；
- **家人留言暖心播报**：家人在网页上写下的嘱咐（如“妈，这趟车票我帮您买好了，您别急”），手机端会立刻弹出大字卡片并以语音清晰朗读，收起后原任务不受干扰。

### 守护圈的三条铁律：
1. **看什么由身份决定**：家人可查看完整办事上下文；社区网格员只看求助与失联报警；邻居只在上门协助时收到提醒。严格防止老人的姓名、验证码和隐私泄露。
2. **只有家人能留话**：老人手机朗读出的留言具有极高信任度，必须严防陌生人伪造假消息。
3. **坚决不做远程控制屏幕**：不做任何形式的“远程代控”。远程投屏和代控往往是电信诈骗团伙最常用的欺诈手段，坚决堵死恶意通道。

## 质量验证体系

以下数字都可用一条命令复现（2026-10-04 实测）：

- **Core 单元与回归测试（109 项，`./gradlew :core:test`）**：覆盖执行主循环、多工具调度协议、敏感操作审批、卡死与死循环检测、任务收尾语义、证据核验正文与收件人解耦；本次新增失败路径用例——工具抛异常不重放已执行动作、空调用批次不崩溃、整批重复调用计入修复预算、执行者自己输入的文字不计入证据。
- **离线 harness（32 组场景 / 181 条断言，`harness/run.sh`）**：针对 mock 提供方的协议级回归，覆盖模型工具协议转换、流式分片重组、在途请求取消、"声明 × 证据"矩阵。mock 按真实提供方的方式**分片**下发（内容每 2 字一帧、工具参数每 3 字一帧），所以"能跑通"本身就意味着分片重组是对的；其中一种模式故意返回非流式响应，让缓冲回退路径也留在回归里。它**不**覆盖真机控件树解析、时序竞态、输入法、截图管线与 OEM 后台限制。
- **服务端测试（34 项 pytest，`cd server && pytest`）**：覆盖亲友配对、心跳失联、求助认领、角色权限隔离、配对码过期 TTL、加入者不可自选身份、配对码失败限速、音频体积防护与语音转写。
- **真机人工校验**：全量语音闭环、悬浮窗手势、双层坐标网格与真实第三方 App 适配，均在实体手机上逐项实测确认；逐条留档见 [`tasks/`](tasks/README.md)。

## 项目工程架构

- `core/AgentLoop.kt`：**纯 Kotlin 核心业务循环**。负责任务驱动、工具执行调度、死循环检测与“交还本人操作”状态机，不依赖任何 Android 视图层代码。
- `core/PhoneTools.kt`：手机操作统一抽象目录（点击、输入、滑动、截图、求助等）。
- `core/OutcomeCheck.kt`：办成证据核验器，负责执行文本、时刻因果与动作一致性检查。
- `app/ScreenAccessService.kt`：Android 无障碍页面解析与动作执行引擎，集成敏感页面识别与拒付词表拦截。
- `app/VoiceSession.kt`：持续语音会话管理，实现自动断句、超时静音检测与随时插话打断（Barge-in）。
- `app/SessionController.kt`：办事任务生命周期管理，串联断点续办、老人确认卡片与亲友求助。
- `app/SkillCatalog.kt` & `SkillStore.kt`：按需技能加载与经验版本管理（候选/启用/退回）。
- `app/MainActivity.kt` & `OverlayService.kt`：老人极简单钮界面与常驻跨应用悬浮接线台。
- `server/`：Python (FastAPI) + SQLite 亲友协作服务端，提供免安装家人看板与轻量语音听写代理。

## 诚实的研发边界与已知局限

我们坚持严谨、求真的科研态度，如实披露当前的系统边界：
1. **任务证据核验**：当前已在手机端上线机械层与证据层拦截（必须先于模型复核通过），能拦截与本轮动作日志或页面上看到的事实直接矛盾的结论；"动手了却没做成"的深度截图视觉对比仍在进一步研发中。
2. **风控路径统一**：部分应用因安全限制屏蔽了控件树，目前依赖截图与坐标点按，该路径的风控统一与安全加固仍在持续完善中。
3. **定位于办事辅助，非全天候医疗监护**：系统聚焦手机数字事务代办；平安确认反映的是设备心跳与交互活跃度，不能等同于老人的生理健康诊断。
4. **技能自进化阶段**：当前已跑通“核验完成 + 老人确认 → 候选技能沉淀 → 家人审核启用”的闭环；基于 GUI 回放与跨界面泛化的自动选版属于计划推进方向。
