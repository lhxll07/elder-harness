## 打开与构建

- 演示：`deck.html`，连续 14 页主讲；右方向键在主讲结尾停止，不误入备份。
- 问答：按 A 打开 15 页目录；点击条目跳转；M 返回主讲；F 全屏。
- 新 PDF：`银龄智办-答辩重构版-2026AIC.pdf`，24 页，1600×900，16:9。
- 旧 PDF `银龄智办-答辩演示-2026AIC.pdf` 与 `提交-省赛/`、`提交-校赛/` 不被构建覆盖。
- 讲稿：`讲稿.md`，14 页连续主线，合计 360 秒排练预算；实际时长需排练确认。

```bash
python3 docs/aic-2026/deck/build.py
bash docs/aic-2026/deck/build_pdf.sh
node docs/aic-2026/deck/check_deck.mjs
```

默认 PDF 输出为重构版；可用 `OUT=...` 显式指定另一文件名。构建依赖 Python 3、Chromium、中文字体与原有 PDF 工具，不调用模型或付费服务。

## 截图副本与检查

`assets/` 只保存演示所需副本。原图不改；两个快递截图中的取件信息用不透明色块替换，原文件与副本的 SHA-256、脱敏区域记录于 `assets/provenance.json`。

重做副本需要 Pillow 与 fontconfig：

```bash
python3 docs/aic-2026/deck/prepare_assets.py
```

`check_deck.mjs` 使用 Node 内置 WebSocket 与本机 Chromium，检查页面数量、字体与图片就绪、文字边界、导航和本地资源。默认把 24 页截图及检查报告写入临时目录；可传入输出目录。检查不代表内容事实已被自动认证。
