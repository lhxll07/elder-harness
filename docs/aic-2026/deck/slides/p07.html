06 / 机制二 · 完成声明与证据绑定银龄智办

自己写进去的字，
不能证明事情办成了。

PAGE页面上观察到的内容可核对
TOOL工具记录的执行事实可核对
SELF_TYPED助手自己输入后，页面显示的文字不背书

来源只是第一道条件；还要核对字段、单位、否定、
新旧观察与跨应用冲突。页面出现文字，不等于业务成立。

例如：输入一条微信消息

“输入成功”
不等于“消息已发送”。

输入动作可以核对；
发送需要本人操作，不能用输入框回声自证。

本地不支持的完成声明，
云端复核也不能翻回通过。
实现：EvidenceCheck / OutcomeCheck / MechanicalFirstReviewer。核验是有限规则下的一致性检查，不是任意业务结果的证明。07
