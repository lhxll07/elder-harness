## 一、体检数据

| 句式/用词 | 次数 | 判断 |
|---|---|---|
| **边界** | **45** | 严重过量。多处只是"限制/范围"的意思，可用具体说法替代 |
| **必须** | **29** | 说教口吻，多为"必须说明/必须写"这类元话语，可删 |
| **如实** | **22** | 自我强调式诚实，反复出现反而**削弱**可信度 |
| **正是** | 20 | 强调句式，保留 5–6 处即可 |
| **而非** | 15 | 对比句式，与下一行同族 |
| **不是…而是** | **12** | 用户明确要求减少 |
| **这不是…** | 4 | 同族 |
| 真正 / 口径 / 恰恰 / 也就是说 | 9 / 10 / 2 / 2 | 轻度超标 |

**对比句式家族（不是…而是 + 而非 + 这不是）合计 31 处**，是本次最主要的语言问题。
