# 老人对照实验：方案与记录表（2026-10-18）

> **目的**：补上“应用价值”唯一缺的硬证据——同一批老人、同一组任务，**自己操作 / 现有手机助手 / 本作品**三组对照。
> **规模**：12—15 位老人 × 3 条件 × 5 任务；单人约 45—60 分钟，两人一组一天可做 4—5 位。
> **口径**：便利样本、组内对照、描述性统计；**不写“显著提升”，不写成功率**。
> **红线**：不产生真实支付、不发送真实消息、不提交真实挂号；手机号、验证码、住址不进入记录表。

---

## 一、设计

**组内三条件**，每位老人依次完成同一组任务：

| 条件 | 操作定义 | 观察者只做什么 |
|---|---|---|
| **A 自己操作** | 老人自己在手机上完成；观察者不提示 | 计时、记录卡点；60 秒无进展给 1 次提示，最多 2 次 |
| **B 现有手机助手** | 老人对手机自带语音助手说出同一句话（Breeno / 小爱 / 小艺，按机型） | 同上；助手做不到就记失败，**不转人工代操作** |
| **C 本作品** | 老人用银龄智办说出同一句话 | 同上；到“交还本人”即算该任务完成 |

**顺序平衡**：6 种顺序（ABC / ACB / BAC / BCA / CAB / CBA）轮换，避免学习效应。每位老人只做一个顺序，记录在表里。

**任务与成功判据**（对应 `tasks/status-tasks.csv`）：

| 编号 | 老人说的话 | 成功判据（观察者逐项勾） | 对应任务 |
|---|---|---|---|
| T1 | “看看我的快递到哪了” | 说出承运商 + 至少一个状态或取件码；只读，不涉及交接 | S11 |
| T2 | “帮我查明天去北京的火车票” | 读出至少 3 趟车次与时间；**不购票** | S10 |
| T3 | “给女儿说我明天去医院” | 文字进入输入框；**发送不算完成**，发送前停住即算完成 | S5 |
| T4 | “字太小了，看不清” | 系统字号确实变大，并能回读新值 | S13 |
| T5 | “帮我点一份黄焖鸡” | 走到结算页并说清金额地址；**付款页停下即算完成** | S4 |

> 每个任务开始前统一重置：清空输入框、退出到桌面、恢复原字号、清空购物车。

## 三、汇总表（做完后填）

| 指标 | A 自己操作 | B 现有助手 | C 本作品 | C−A | C−B |
|---|---:|---:|---:|---:|---:|
| 完成率（2+1）/ 总次数 | | | | | |
| 独立完成率（2）/ 总次数 | | | | | |
| 完成用时中位数（秒，仅完成项） | | | | | |
| 平均提示次数 | | | | | |
| 平均求助次数 | | | | | |
| 误触总数 | | | | | |
| 危险动作总数（应为 0） | | | | | |
| 能说出当前状态的比例（B/C） | NA | | | | |
| 5 秒内能停下的比例（B/C） | NA | | | | |
| 有用性均值（1—5） | | | | | |

**分析口径**：

1. 只报描述统计与配对差值中位数；n=12—15 不做显著性宣称。
2. 用时只统计完成项，避免“没做完所以很快”的偏差。
3. 危险动作总数单独列；即使为 0，也只写“本轮未触发”，不写“零风险”。
4. 每位老人的三种条件都记录完整才算一条；缺一条的整人剔除，不补。

## 四、知情同意（口头，逐字念）

> 我们在做一个帮老人用手机办事的工具，想请您试用一下，大约 40 分钟。
> 过程中我们会看您怎么操作、记时间和卡点，**不录像、不记姓名、不记手机号**。
> 不会真的花钱、不会真的发消息、不会提交挂号，到付款或发送前就会停下。
> 您随时可以停，停了也不影响任何事。您愿意吗？

书面版另附一页签字（姓名可只签姓），与记录表分开保存。

## 五、执行清单

**材料**：测试手机 1 台（已装本作品、已登录测试账号）、秒表、记录表打印件、知情同意页、充电宝。

**角色**：1 人主持（说话、递手机），1 人记录（只记不看提示）；主持与记录不互换，避免提示口径漂移。

**流程（每位老人）**：

1. 念知情同意，确认理解；记录年龄组、性别、熟练度、顺序。
2. A 条件：5 个任务依次做；每个任务前重置；60 秒无进展给 1 次提示。
3. 休息 2 分钟，问“刚才那样自己弄，累不累”（只记原话）。
4. B 条件：同一组任务，对语音助手说同一句话；做不到就记 0，不代操作。
5. C 条件：同一组任务，用本作品；到“交还本人”即算完成。
6. 问三个问题：哪个最省事？哪个最放心？愿不愿意给家里人用？
7. 送小礼物，结束；当天把 CSV 录完，不留到第二天。

**时间预算**：5 任务 × 3 条件 × 约 2 分钟 = 30 分钟；加讲解、休息、问卷约 50 分钟。12 位老人约 10 小时，两人两天可完成。

---

## 六、写进报告时的三句话

1. **样本**：12—15 位、60 岁以上、便利样本；年龄组与熟练度分布如实列出。
2. **结果**：只报“完成率 / 用时中位数 / 提示与求助次数 / 危险动作数”的组间对照，不做显著性宣称。
3. **边界**：组内对照、单机型、观察者在场；不外推为总体成功率，也不替代真实家庭环境的使用。

## 七、如果时间不够（10 人 × 4 任务）

砍掉 T2（火车票，链路最长），保留 T1、T3、T4、T5；10 位老人 × 3 条件 × 4 任务 = 120 次，约 6—7 小时。**宁可样本小、记录完整，不要人次多、缺项多。**
