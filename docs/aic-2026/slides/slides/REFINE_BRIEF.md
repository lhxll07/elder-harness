## 设计系统（硬约束，不得违反）

**配色只有三支**：
| 用途 | 色值 |
|---|---|
| 深青（主） | `#0A2E3A` / `#0E3F4E` |
| 浅青（浅底衬、图线） | `#E3EEF1` |
| **暖橙（全篇唯一强调色，用量 ≤10%）** | `#D9722B`（大字/图形）· `#E9A06B`（深底上的字）· `#C2410C`（浅底小字） |
| 中性 | 白 `#FFFFFF`、浅灰 `#F5F7F8`、正文 `#1F2937`、次要 `#6B7280`、线 `#E5E7EB` |

**字号（投影可读，不得低于）**：页标题 ≥36px；正文/卡片 ≥24px；注释 ≥19px；大数字 128–192px。

**每页信息密度**：1 个核心结论（标题即结论句）· 主文字 ≤3 行最优、绝不超 6 行 · 文字面积 ≤30% · 表格 ≤1 张。

**禁止**：第二个色相、渐变荧光、发光边框、3D 图表、艺术字、弹跳/旋转动画。

## 精修要查的清单（逐条过）
1. **文字有没有压到画面主体**？——最严重的问题，先查这个
2. **画面与背景有没有硬边**？——如果页面上有暗罩/渐变，其基色必须**等于该画四角实测底色**，否则会有可见色缝。用 `python3 -c "from PIL import Image;im=Image.open('art/X.png').convert('RGB');print(im.getpixel((3,3)),im.getpixel((im.size[0]-4,im.size[1]-4)))"` 实测
3. **页面家具是否齐全一致**？——正文页（p02–p11）应有：顶部左侧 `能工智人 · AIC-2026-86471901`、顶部右侧 `银龄智办 · 可信自进化跨应用助老智能体`、右下角页码。深色页用 `rgba(255,255,255,.42)`，浅色页用 `#9AA5AB`。左右边距统一 **76px**
4. **标题是否折行难看**？——中文不要出现"会点外/卖"这种断法，必要时手动 `<br>`
5. **底部有没有溢出**？——内容不得触碰页脚区（底部 60px 内）
6. **对齐**：同页元素左边缘一致；字号层级清晰
7. **留白**：版面不要挤满，也不要有大块突兀空洞

## 铁律（违反即作废）
- **不得新增或修改任何事实**。数字、结论、措辞必须与原文一致。你只能改**排版、间距、字号、配色、层级**，不能改**内容**。
- 不确定某句话能不能改 → **不改**。
- 不要引用外部图片、不要联网找素材。
- 改完必须**自己渲染一次确认**（`./render_one.sh pNN` + read_image），确认没有溢出、没有压图、没有难看折行。
- 只改分配给自己的文件，改完**不要**跑 `build.py`（避免与他人冲突）。
