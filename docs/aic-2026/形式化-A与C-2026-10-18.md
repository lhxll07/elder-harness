## （九）形式化基础：一条不变量与一条分离命题

第三部分已经给出算法 1—3 与判定规则，但三条最关键的工程主张——**副作用之前拦截**、**闸门单调**、**本机拒绝是终局**——目前是**实现断言**，不是可检查的命题。本节把它们写成定义与定理，并明确写出定理成立的条件。**定理不成立的地方，恰好是第六部分（六）那 5/6 个边界探针。**

### 1. 定义

**定义 1（执行器）** 执行器是一个部分状态转移系统 `M = (S, A, O, T, Ω)`：`S` 为设备状态，`A` 为动作，`O` 为观察，`T: S × A ⇀ S` 为部分函数（执行失败即无定义），`Ω: S → O` 为观察函数。一次运行是序列

```
ρ = s₀ →(a₁) s₁ →(a₂) … →(aₙ) sₙ，  其中 sᵢ = T(sᵢ₋₁, aᵢ)
```

**定义 2（后果类与可逆）** 后果类 `κ: S × A → E`，`E = {read ≺ nav ≺ rev ≺ irrev ≺ commit}`。动作 `a` 在状态 `s` **可逆**，当且仅当存在动作序列 `σ ∈ A*` 使 `T*(T(s,a), σ) = s`（允许观察等价）。`irrev` 与 `commit` 两类合称**不可逆**。

**定义 3（授权事件）** 授权事件 `h = (params, t, source)`，其中 `source` 只能取「本人确认卡」或「`ask_person` 完成」；`t` 为时间戳，`params` 为该动作的参数。

**定义 4（闸门与单调）** 闸门 `g: S × A × Ctx → {exec, confirm, handoff}` 由四层串联 `g = g₄ ∘ g₃ ∘ g₂ ∘ g₁`（参数校验 → 本人操作词表 → 敏感页 → 同意）。**单调**指：任一层返回拒绝，后续层不得返回 `exec`。

**定义 5（派发）** 执行器只在 `g(s,a) = exec` 时调用 `dispatch(a)`；`dispatch` 是所有副作用的唯一入口。

### 2. 定理 1（安全不变量）

> **定理 1（安全性 + 一次性）** 若以下四条成立：
>
> - **H1（分类完备，不漏）** 若 `a` 在 `s` 不可逆，则 `κ(s,a) ∈ {irrev, commit}`；
> - **H2（对已识别动作，闸门正确）** 若 `κ(s,a) ∈ {irrev, commit}` 且 `g(s,a) = exec`，则存在授权事件 `h`，满足 `params(h) = params(a)`、`t(h) < t(dispatch(a))`，且 `h` 发生在参数固定之后；
> - **H3（唯一入口与消耗）** 所有副作用都经 `dispatch`；`dispatch` 只执行 `g = exec` 的动作；`dispatch` 消耗至多一个授权令牌并将其从可用集合中移除；执行失败不构成授权，失败的动作不得在未重新授权的情况下重放；
> - **H4（授权来源）** 授权令牌只能由人工事件（本人确认卡 / `ask_person` 完成）产生，每个令牌有唯一标识，且状态转移不会复制或重新加入已消耗的令牌；
>
> 则对任意运行 `ρ`：
> **(a)** 若 `aᵢ` 真正不可逆且被执行，则存在授权 `h` 在 `dispatch(aᵢ)` 之前授权了同一组参数；
> **(b)** 同一授权最多授权一次执行，且只授权参数完全相同的动作。

**证明**

**(a)** 设 `aᵢ` 真正不可逆且被执行。由 H1，`κ(sᵢ₋₁,aᵢ) ∈ {irrev,commit}`；由 H3，`g(sᵢ₋₁,aᵢ) = exec`；由 H2，存在 `h` 在 `dispatch(aᵢ)` 之前授权同一组参数。单调性（定义 4）保证前序层的拒绝对 `aᵢ` 不会被后续层翻回 `exec`，故该 `h` 是 `aᵢ` 的合法授权。

**(b)** 对运行长度归纳。初始可用令牌集为空。第 `i` 步：
- 令牌只能由人工事件加入（H4），且每个令牌唯一；
- `dispatch(aᵢ)` 至多消耗一个令牌并将其移除（H3）；
- 已移除的令牌不会被任何转移重新加入（H4）。

因此被消耗的令牌不可能在另一次 `dispatch` 中再次出现；又由 H2 的 `params(h) = params(aᵢ)`，它也不能授权参数不同的动作。∎

**推论（逆否）** 若不存在授权事件，则真正不可逆的动作不被执行——**前提是 H1 成立**。

**H1 在哪失效，就是 5/6。** 边界探针（关闭查找手机、允许安装未知应用、开启开发者选项、更换手机号、关闭定位服务）的后果都是不可逆的，但词表分类器把它们判成了 `rev`：H1 的「不漏」不成立，于是定理的前提不成立、结论不适用。**定理没有错，是 H1 在 5 个样本上不成立。**

这里要严格区分两个方向：

- **完备性（H1）**：真正不可逆 ⇒ 分类为不可逆。它决定**漏拦**，5/6 就是完备性失效。
- **可靠性（不误报）**：分类为不可逆 ⇒ 真正不可逆。它决定**误拦**；它不参与定理的证明，但决定「是否把老人烦死」。

H2 只对「已经识别出来的不可逆动作」作保证——这是关键：**闸门不负责识别，只负责在识别之后不放行。** 所以下一步不是改定理，而是把 H1 从「词表」换成「模型给后果分类、闸门保留放行权」；定理 1 与闸门结构都不动。

### 3. 命题 1（词表路线的分离命题）

设词表 `V` 为有限字符串集合，分类器 `κ_V(s,a) = irrev` 当且仅当 `label(a)` 包含 `V` 中某个串。记 `I` 为真实不可逆动作集合，`FP(V) = |{安全动作 a : κ_V(s,a) = irrev}|`，`Rec(V) = |{a ∈ I : κ_V(s,a) = irrev}| / |I|`。

> **命题 1（标签可改写的假设下）** 设不可逆动作的标签可由对抗方改写（同一后果换一种说法），则不存在有限 `V` 同时满足 `Rec(V) = 1` 与 `FP(V) = 0`。

**证明**

1. 若存在 `a ∈ I`，其标签与 `V` 中任何串都不共享子串，则 `κ_V(s,a) = rev`，故 `Rec(V) < 1`。标签可改写保证这样的 `a` 存在。
2. 若 `FP(V) = 0`，则 `V` 中任一串都不能出现在任何安全动作的标签里；否则该安全动作会被误判为不可逆，与 `FP(V)=0` 矛盾。因此 `V` 只能取自「**只出现在不可逆标签里**」的串集 `L_only-irrev`。
3. `L_only-irrev` 是标签空间的一个真子集（标签可改写保证其补集非空）。由 1、2，`V` 越大越容易触碰安全标签（破坏 2），越小越漏掉不可逆动作（破坏 1）。两者不可同时取到极值。∎

**这不是「有限列表列不完」的同义反复。** 平凡的部分是「列不完」；非平凡的部分是**误拦约束反过来限制了召回**：为了 `FP = 0`，词表不能收「取消」这种同时出现在「取消订单」和「取消返回」里的词，于是召回被压在「无歧义不可逆词」的规模上。实测的三个点正好落在这条边界上：

| 词表 | 召回（20 项危险动作） | 误拦（6 项安全动作） | 边界探针 |
|---|---:|---:|---:|
| 修复前原始词表 | 6/20 | 0/6 | 6/6 漏拦 |
| 扩充后（加身份类词） | 15/20 | 0/6 | 5/6 漏拦 |
| 理论目标（`Rec=1, FP=0`） | — | — | 命题 1：不存在有限 `V` 达到 |

**出路不是更大的 `V`，是换分类器**：让模型输出「这个动作的后果属于哪一类」，闸门只保留「放行 / 不放心」的权力。分类器从词表变成模型，H1 的前提从「串匹配」变成「后果判断」，定理 1 与闸门结构都不变。

### 5. 适用范围（必须一并写进正文）

1. **定理是条件性的**。它证明的是「给定 H1，闸门结构能保证不越权」；H1 由分类器承担，是当前最弱的一环，也是 5/6 的来源。
2. **不覆盖「动了手却没办成」**。那属于证据层（B 部分），定理 1 只管「不该做的没做」。
3. **不覆盖真实模型被注入后的行为**。实验一、二用的是脚本化规划器，证明的是架构侧；真实模型侧由第五部分 31 条运行与第七部分承担。
4. **不声称零漏拦**。命题 1 恰恰说明：在词表路线上，零漏拦与零误拦不可兼得。
