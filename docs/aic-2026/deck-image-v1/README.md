# 银龄智办 · 17 页生图答辩

## 制作约定

- 用户确定 16—17 页，本版固定 17 页、16:9、3840×2160。
- 每页调用内置生图工具直接生成完整幻灯片，再将整页图片拼为 PDF，不用 HTML/SVG 渲染替代生图。
- 每轮只生成一张。生图后停止，等待用户说“继续”；下一轮先归档上一张，再生成下一张。
- 画面采用深蓝、暖金、瓷白；科技与人文结合，饱满精致，强调层次、图示和投影可读性。
- 叙事采用肯定句与价值主张，重点呈现能力、创新、机制、实绩及应用价值。
- 不改旧演示、冻结提交件、项目代码及原始数据。
- 沿用匿名参赛方式：能工智人团队，AIC-2026-86471901；不出现学校、校徽、指导教师。

## 文件

- `storyboard.md`：整套 17 页的叙事、准确文案及画面方向。
- `sources.md`：项目事实、数据口径及来源。
- `prompts/p01.txt`：第一张封面的完整生图提示词；后续逐页保存对应提示词。
- `progress.json`：制作进度；生图工具返回的文件位置在后续归档时补记。
- `slides/p01.png` 至 `slides/p17.png`：最终整页图片。
- `build_pdf.py`：图片齐备后合成演示 PDF，可显式生成连续前缀的预览版。

```bash
python3 docs/aic-2026/deck-image-v1/build_pdf.py
python3 docs/aic-2026/deck-image-v1/build_pdf.py --partial
```

## 连续制作顺序

1. 读取进度，检查上一轮工具返回的图片。
2. 将选定图片从工具实际返回位置复制到 `slides/pNN.png`，核对文字和 16:9 画面。
3. 在进度中记录文件、工具返回位置、审核状态。
4. 按分镜与统一视觉规范保存下一页提示词。
5. 只生成下一张完整幻灯片，然后等待用户继续。
6. 17 张全部归档后合成 PDF，检查页数、顺序、尺寸与清晰度。

数据随图展示样本口径；生成场景和界面采用示意表达；应用路径采用规划表达。荣誉、知识产权、合作和营收只使用已有事实。
