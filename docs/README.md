## 维护约定

- 根 README 只保留项目简介、启动方式与入口；实现细节放 `architecture.md`，验证结果放 `testing/README.md`。
- 当前方案与答辩版本以参赛导航为准；源文件、生成产物和冻结提交件分开维护，不自动覆盖提交件。
- 保留有来源的实验、审查与文献记录，不把历史结果写成当前版本成绩。
- 密钥、数据库、真实页面和原始日志不入库；真机运行保存在被忽略的 `tasks/runs/`。
- 自动备份、预览、依赖与构建缓存不入库；维护源文件和必要离线资产，不新增重复的状态文档。
