# 《银龄智办》演示短片 · 分镜脚本

技术形态：Three.js（WebGL2）+ GLSL，离屏逐帧渲染 + ffmpeg 合成
画幅：1080p · 60fps · 总长 **60s**（9 镜）
旁白：无。**大字幕 + 屏幕内文字**承担信息（这既是易读性要求，也省掉配音与口型风险）
素材边界：画面中出现的所有数字、文案均来自 README / `docs/testing/device-baseline-2026-09-29.md`；**拟研发内容一律带「拟」标记或虚线边框**，不与已实现能力混淆

> **60s 版与 150s 版的区别**：不是等比例压扁，而是每镜只留**一个动作**。150s 版里
> 「盲页面」的整段 ABA 对照被压成一次转场，「技能自进化」的三台回放机压成一个验证脉冲，
> 「分级执行」三级台阶只演示橙、红两级。
> 下面的时间轴是 60s 版；括号内标注被砍掉的内容，供将来出长版时取回。

## 一、视觉系统（先定死，避免每个镜头各写一套）

### 颜色

直接取老人端 `Ui.kt` 的 `Elder` token，让短片和产品是同一套颜色：

| 变量 | 值 | 用途 |
|---|---|---|
| `brand` | `#1A7F6B` | 主线、正常流转、语音球 |
| `brandDeep` | `#12604F` | 体积光、地面反光 |
| `ink` | `#17202A` | 深底 |
| `attention` | `#C46A14` | 需要老人决定（橙色） |
| `problem` | `#C0392B` | 谎报、拒绝、做不到 |
| `good` | `#1E8449` | 已核验通过 |
| `card` | `#FFFFFF` 93% 不透明 | 卡片（沿用悬浮窗的半透明设定） |

底色走近黑蓝（`#0E1418`），让手机屏幕和卡片成为唯一亮点——观众的注意力天然落在"老人看到的那一屏"。

### 四层视觉语法（全片复用，不要每场新造）

| 层 | 视觉 | 语义 |
|---|---|---|
| **页面层** | 手机屏幕浮板，白色卡片贴图 | 老人眼前的真实应用 |
| **抽象层** | 细线格 + 发光节点（无障碍树） | 机器看见的页面结构 |
| **推理层** | 环流粒子 + 涡旋 | 云模型与工具调用 |
| **约束层** | 光栅、滤镜、阶梯、徽章 | 本地校验与安全边界 |

"约束层"是本片的辨识度来源。别的 AI 演示都在拍推理有多强，这一部要拍**约束在哪里生效**。

### 字体与字号

用斜排的中文字体（思源黑体 / Noto Sans SC），**屏幕内文字最小 40px（1080p 下）**，字幕 56px。UI 文字走 2D canvas 烘焙成贴图再贴到 3D 平面上——中文字形不适合在着色器里做 SDF。

## 二、分镜表（60s 版）

时间轴以成片计。每镜只留**一个动作**——信息靠"字幕 + 画面里的一件事"，不靠镜头内塞满细节。

### 镜头 1 · 开机（0:00–0:06，6s）

| 项 | 内容 |
|---|---|
| 画面 | 黑场中一点绿光呼吸。粒子从四周被吸入，聚成一条悬空的**阿基米德螺旋**，12 个发光节点串在上面——每个节点是一次真机实测过的任务（课表、外卖、快递、火车票、字体设置…）。镜头沿螺旋轴缓慢推入。 |
| 文字 | 主标 **银龄智办** 从节点之间穿过；右下角小字 **可信跨应用助老智能体** |
| 音 | 低频嗡鸣；每颗节点到位一声短音，音高逐颗上行 |
| GLSL | 粒子由 3D simplex + 旋转场驱动；近景粒子按深度做 `smoothstep` 发光；螺旋线用线宽着色器。全片只在这里用一次"满屏粒子"，后面不再重复 |

### 镜头 2 · 一屏一件事（0:06–0:12，6s）

| 项 | 内容 |
|---|---|
| 画面 | 螺旋收束成手机浮板，正对镜头。屏幕上只有三样东西：一行状态（绿点 +「我在」）、一个直径 200dp 的大圆按钮、下方一行提示。**没有图标网格、没有列表**。按钮被按下，圆从 `brand` 绿渐变为 `attention` 橙——产品里"绿＝空闲、橙＝麦克风开着"的那套信号。 |
| 文字 | 字幕 **老人说出需求** / 辅：一屏一件事，一个按钮，颜色就是状态 |
| 音 | 按钮按下：木质闷响；随后环境底噪"被打开" |
| GLSL | 按钮＝径向渐变圆盘 + 衰减波纹环；屏幕亮度略高于环境，边缘一圈 `brand` 辉光 |

### 镜头 3 · 插话与步骤播报（0:12–0:18，6s）

| 项 | 内容 |
|---|---|
| 画面 | 声波环离开屏幕。助手回话时，声波环**从内侧被打断、反相**——这就是「插话立刻闭嘴」。随后助手说的每一步以文字气泡从屏幕浮起（"正在打开微信"），一个接一个，不是一次性结论。 |
| 文字 | 字幕 **说得进去，也插得进去** / 辅：说完自动接、说话时能打断、每一步都念出来 |
| 音 | 人声环（低通）→ 打断瞬间的短促切音 → 气泡上浮的轻点 |
| GLSL | 极坐标噪声 + 时间相位做声波环；打断时给环反向相位、颜色 `brand`→`attention`、快速衰减 |

### 镜头 4 · 办事循环（0:18–0:26，8s）

| 节拍 | 画面 | 文字 |
|---|---|---|
| 4a 看见（3s） | 浮板上，**无障碍树被抽出**：带文字的节点升为发光文字块，细线连成三层结构 | **看见** |
| 4b 看不见时（3s） | 树的 alpha 整体塌到 0，只剩位置残影；浮板表面转为不透明并布满噪点——"读不到控件"。浮板背面浮出一张截图被送进管线 | **也看得见看不见的时候** / 树里一个节点都没有 → 只能靠截图 |
| 4c 规划（2s） | 镜头拉远，浮板缩成环流中心一粒；节点文字、对话记录、工具目录汇成一条发光文本带卷入涡旋，吐出 `tap` / `input_text` / `screenshot` | **云模型只负责决定下一步** |

| 项 | 内容 |
|---|---|
| 音 | 4a 纸页翻动；4b "耳朵被捂住"的低通闷声 → 一声快门；4c 管风琴长音铺底 |
| GLSL | 无障碍树用实例化 billboard + 连线按 `aDepth` 衰减；**"变盲"用一个全局 uniform `uBlind`（0→1）**，同时给浮板加噪点与法线扰动——这个 uniform 全片复用；涡旋＝屏幕空间极坐标旋转场，粒子被 `1/r` 吸引 |

## 三、技术实现要点

### 1. 时间轴必须是可寻址的

不要用 `requestAnimationFrame` 的增量时间。整片由一个纯函数驱动：

```js
// 每帧只做一件事：把时间喂进去
window.__renderAt = (tSeconds) => { scene.update(tSeconds); renderer.render(scene, camera); };
```

离线渲染时用无头浏览器逐帧调用，`ffmpeg -framerate 60` 合成；预览时用 rAF 驱动同一个函数。**禁止任何依赖上一帧状态的写法**（累加位移、`+=` 速度），否则抽帧渲染会抖。

### 2. 镜头/场景是一个轨

写一个极简轨：

```js
const TRACK = [
  { at: 0.0,  shot: 'spiral-open'  },
  { at: 14.0, shot: 'voice-circle' },
  // ...
];
```

每镜内部用 `local = t - at` 自行做入场/出场。跨镜的公共元素（手机浮板、无障碍树、发光文本带）常驻场景图，只改参数——这正是"约束层"能贯穿全片的原因。

### 3. 中文字形走烘焙，不走 SDF

UI 面板与字幕用 2D canvas 绘制 → `CanvasTexture` → 贴到平面。好处：字体渲染正确、和 Android 端排版接近、可截图对照。只有抽象层（粒子、涡旋、光栅、破碎）写在 GLSL 里。

### 4. 手机屏幕是渲染到纹理的

屏幕内容单独渲进一个 `WebGLRenderTarget`（原生比例，如 1272×2800 的一半），再作为贴图放在 3D 浮板上。这样：屏幕内可以和 3D 世界做交互（波纹、撕裂、噪点、截图被"抽走"）。

### 5. 后期

`EffectComposer`：bloom（阈值偏高，只让发光元素溢出）→ 色差（破碎/打断瞬间拉高）→ 暗角 → 胶片颗粒。**统一在最后做一次 tone mapping**，避免逐帧不一致导致闪烁。

### 6. 无障碍与降级

`prefers-reduced-motion` 下降低粒子量与镜头运动幅度；短片本身也可另出一版"低动效版"（帧率不变，去掉螺旋与涡旋的持续旋转）——这与项目"适老"的立场是一致的，评审会注意这种一致性。
