# 《银龄智办》演示片 · 分镜脚本 v2（250s）

> **作品名称**：银龄智办——可信跨应用助老智能体  
> **技术形态**：Three.js（WebGL2）+ GLSL 离屏逐帧渲染 + ffmpeg 高清合成  
> **画幅标准**：1920×1080 · 60fps · **总时长 250.0 秒**  
> **配乐节拍**：96 BPM（1 拍 = 0.625s，1 小节 = 2.5s，全片共 100 拍）  
> **叙事形式**：无口播旁白，**大字中英双语字幕 + 3D 屏幕交互动效 + 空间排版**直观传递信息  
> **素材边界**：所有数字、案例与边界严格对应 `README.md` 与 `docs/testing/device-baseline-2026-09-29.md` 真机实测；拟研发部分带“拟”字角标或半透明虚线框。

本片面向**人工智能算法精英大赛**与科技成果评审，全片围绕**“如何让大模型既能帮老人办事、又绝不越权添乱”**展开，层层递进：

## 一、运镜与动作库（无抖动、连续平滑）

全片禁止手持抖动与硬切，所有镜头均由连续平滑曲线驱动，镜头之间依靠**几何形变**无缝衔接：

| 运镜指令 | 镜头运动方式 | 叙事功能 |
|---|---|---|
| `dollyIn(k)` / `dollyOut(k)` | 沿视线连续推近 / 拉远 | 聚焦关键操作细节、拉远展现全局网络 |
| `craneUp(k)` / `craneDown(k)` | 垂直升降，带轻微俯仰 | 展开立体交互空间、压低情绪制造专注 |
| `truckX(k)` | 横向水平平移（视差明显） | 桌面任务多场景横移并置、自然转场 |
| `orbit(target, deg)` | 绕主体平滑环绕 | 展示 3D 手机结构与界面正反面 |
| `follow(target, k)` | 跟随运动物体运动 | 跟随执行方块上行、求助卡片飞行 |
| `pushToDetail(target)` | 快速推近到局部微距充满画面 | 切点入口衔接 |
| `pullToReveal(target)` | 从局部微距平滑后退揭示全貌 | 切点出口展开 |

## 二、全局工艺与设计标准

1. **真实物理质感**：
   - 手机模型具有厚度、倒角高光与玻璃盖板，屏幕内嵌 0.4mm；
   - 材质统一为：哑光深色金属、磨砂玻璃、哑光白纸与自发光屏幕；全片屏幕永远是画面核心光源。
2. **色彩语义规范（沿用产品设计系统）**：
   - 🟢 `brand`（#1A7F6B，常态待命、健康放行）
   - 🟠 `attention`（#C46A14，倾听中、需要确认）
   - 🔴 `problem`（#C0392B，拦截谎报、敏感红线、拒绝越权）
   - 🟩 `good`（#1E8449，证据核验通过）
   - 📄 `card`（白色 93% 不透明度磨砂卡片）
3. **形变转场（本片核心视觉记忆点）**：
   - 每一个切点都是**上一镜的物体无缝变成下一镜的物体**，相机动量在切点两侧保持方向与速度连续，绝无“停顿后再重新起跑”。

## 五、精选画面小巧思清单（评审加分细节）

1. **真实倒影与延迟**：首页大圆钮被按下时，波纹在玻璃盖板内层形成微弱倒影，倒影比本体运动慢 2 帧，凸显真实盖板厚度。
2. **打断真实塌平**：老人插话打断瞬间，助手的五条声波纹并非突兀消失，而是“瞬间被声压压平为一条直线”，随后变橙聆听。
3. **坐标编号与置信度挂钩**：盲页相对坐标网格的数字标签字号，随模型定位置信度高低微幅缩放，视觉体现严谨算法底座。
4. **诚实计数不归零**：第 Ⅴ 章台阶旁的打扰计数器从 0 走到 9 后，永久停留在“9 次直接代办，1 次交还本人，0 次多余打扰”，彰显真实数据力量。
5. **手写温暖回执**：家人在网页端点击认领后，老人家端浮出的“我来处理”卡片带有微温润的手写质感，与冰冷的机器字体形成鲜明温情对比。
6. **隐私磨砂罩真实折射**：求助卡片掠过时，身份证号与住址上方的半透明磨砂罩边缘带有精细折射光，表明隐私物理隔离。
7. **回退徽章金属下沉**：技能自进化回退时，退化路径上的徽章伴随清脆的下沉感换回上一版，表达对安全边界的坚决捍卫。
