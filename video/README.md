# 演示视频工程

当前采用 v19，制作与重建步骤见 [v19 说明](docs/fusion-v19-blender.md)；最终提交件见 [省赛清单](../docs/aic-2026/提交-省赛/README.md)。这是演示制作工程，不是真机评测结果。

| 目录 | 内容 |
|---|---|
| `src/`、`render/` | 动画源与渲染、编码、检查脚本 |
| `quality/`、`assets/` | 版本化制作源、设备/光场资产、字体与音频 |
| `docs/` | 制作决策、版本说明与复现步骤 |
| `out/` | 本地生成交付与历史审片，不入库 |
| `tmp/` | 本地预检和音频工具环境，不入库 |

安装 Node 依赖使用 `npm ci`。完整 v19 构建还需要 Blender、FFmpeg 与 Python 环境，按版本说明执行，不由产品构建触发。

`out/review/fusion-v19-blender/` 是当前完整交付，包含成片、帧、源快照、许可与验证记录；不要按普通临时缓存删除。历史声音交付也可能是新版本的构建输入。清理时仅删除已确认无用的预检目录、散落日志与空目录，保留工具环境和有效交付。
