# v19 · Blender 质感升级

## 范围

以最后完整交付的 v18 画面及声音为基线。全片仍为 196 秒、60 fps；叙事、页面信息、操作顺序、运镜轨迹、自然微晃、章节时长与音效落点保持不变。原生 3840×2160 逐帧渲染，再以 Lanczos 降采样导出 1920×1080。无旁白，不打开审片页、不自动播放，旧交付不覆盖。

本轮不是在成片上叠锐化或滤镜，也不把所有页面变成重拟物玻璃。采用混合渲染：Blender 真正制作资产和物理照明，Three.js 保留原有程序化叙事动画与实时页面；保证技术信息可读、跨镜继承稳定。

## 升级内容

### Blender 设备

使用 Blender 5.2.2 生成四套细化倒角、闭合壳体和法线的几何资产，保留手机 `.70 × 1.52 × .078` 尺寸、`.098` 主圆角及现有屏幕层级。运行时先加载几何缓存，再由原工厂生成设备；不更改屏幕 UV、Z 顺序、`userData` 或原有动画对象。侧键、镜头和金属材质克制调整。手部只细化接缝法线、减弱颗粒与塑料高光，不增加写实纹理。

### Blender 灯光空间

Cycles / OptiX、64 samples、降噪，制作十套原生 4K 建筑光场：深蓝纵深、靛蓝廊柱、玉灰层叠、暖灰双窗、青灰观察窗、独立双光井、鼠尾草折面、石墨台阶、开放玉绿及深蓝收束。使用圆润边缘、宽面柔光和真实间接照明，无库存素材，无烟雾、镜头污渍或装饰性机械。

光场作为低对比背景与现有时间驱动形态融合；原有 3.2 秒章节过渡与权重保持，背景有极轻视差，字幕下方保持净区。另制作线性 HDR 棚拍反射环境供设备 PBR 材质使用；不是把曝光后的背景图当环境图。

### 全片页面

统一卡片的单层柔影、极轻纸感渐变、内缘和按钮层次。家人留言区、后半段阅读工作台、证据卡与技巧目录使用同一套材质语汇；不改文字、布局、比例和动画。透明页面使用单次双面渲染以避免不必要的叠层。降低后处理泛光、色散和颗粒，保持手机、卡片、字幕之间的清晰层次。

4K 全章乱序预检发现冻结管线的暂停透明度状态会污染重新访问的 16 秒画面：暂停后的 `fade(phone, 1)` 覆盖了手机入场自身的透明度。新版将暂停改为在当帧计算出的材质透明度上乘同一个暂停系数，不再在下一次调用恢复一组旧值；暂停曲线、起止、镜头和操作时序不改。修正后 51 个采样与 6 个跨章乱序复测均通过逐字节确定性检查。

## 不变的事实边界

保留机制可视化、虚拟数据等标注；不伪造实机录像或实测结果。家人提供线索，老人核对并本人提交；主任务仍为“已提交、待医院确认”。`SELF_TYPED` 不充当外部证据，本地审计先于独立复核。方法提炼、验证、家人采用、按需复用保持 v18 的顺序与边界。

## 声音

直接复制 `fusion-v18-sound` 的最终 AAC 音轨，不重作曲、不重新混音、不重新编码。通过叙事源码契约确认时钟和动作表达式不变，检查最终封装的音轨 packet hash 与原片一致。75 个离散动作落点、26 段连续动作声音及原授权继续保留。

## 复现

```bash
cd video
blender -b --factory-startup --python render/blender_device_v19.py
blender -b --factory-startup --python render/blender_studio_v19.py -- --samples 64
RENDER_SCALE=2 node render/quality_v19_check.mjs tmp/quality-v19-check-4k
OPENBLAS_NUM_THREADS=2 tmp/audio-venv/bin/python render/quality_v19_render.py
```

设备与光场资产位于 `quality/v19/assets`，独立动画源位于 `quality/v19/src`。完整交付默认写入 `out/review/fusion-v19-blender`，包含 MP4、无声画面版、原生帧、源快照、Blender 资产与生成脚本、接触表、叙事契约和验证报告。`--resume` 仅允许继续未完成的输出目录，不覆盖完成交付。

验证包含原生 4K 采集、多时点构图、乱序确定性、逐帧连续性、黑帧/孤立跳变、完整解码、最终格式、时长、画面/音轨 packet identity，以及旧基线哈希。静态图像审查和数值验证不等同于人耳主观试听。
