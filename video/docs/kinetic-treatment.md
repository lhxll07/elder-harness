# 折叠操作，留下决定 · 视觉改稿

本轮只修改视频，不修改 Android、core 或 server 产品实现。沿用 v16 的复诊主线、214 秒总时间轴、真实顶部悬浮窗形态。开场、架构总览和片尾保留。修改范围为第三至第十镜，44—206 秒。

## 主视觉

同一件事、同一组页面、同一个悬浮窗。页面从正面进入侧面的纵深，折叠成为风琴长卷；真正需要本人参与的信息像书签一样留下。使用实际关节旋转和连贯的页缘，不用缩小、透明消失代替折叠。

背景由页面遮挡、落地阴影和柔光构成；避免独立的技术展台、门禁机器、盾牌、无意义粒子和持续环绕。每镜只在关键时刻停留一句主文案，字幕承担准确说明。

讲解短标使用相机安全区与轻暗描影，在白色页面和深色背景上都保持对比。本人提交段的主文案移到手机左侧留白，保留原页面的阅读完整性。家人端页面沿同一屏幕柔和叠化，不用硬切替代交互。

## 连续性与真实性

- 所有对象由绝对时间确定；倒序访问和重试渲染不得累积状态。
- 每镜前后各留共同的正面手机、相机姿态和渐变窗口，避免旧版二三镜的孤立跳变。
- 屏幕内仍是医院示例页面与已有顶部悬浮窗。折叠长卷、书签和阅读尺是机制可视化，不伪装为已经上线的新界面。
- 家人留言先到本人眼前，核对后才继续；留言不是远程操作指令。
- 提交由本人完成。最终业务状态为已提交、待医院确认；不表现为预约成功或支付完成。
- 表格重排为阅读方法示意，不作为已经测得的泛化收益。T2 保持待实机验证，候选不自动采用。

## 输出

仅重新渲染修改的八个完整分镜，原生 1920×1080、60fps，连续编码为一个 162 秒 MP4。保留 v16，不自动打开审片页。运行 `node render/kinetic.mjs --version 2 --workers 2`；新版本目录保存源码、素材、字幕、帧和验证报告。
