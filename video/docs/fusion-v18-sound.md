# v18 · 声音修订 5

本轮只把 v17 声音第四版（v04b）的动作响应重放到 v18 冻结画面上，不重新作曲，不改钢琴预混。

## 与上一版的差异

- 画面改为 v18：结尾不再有“三项能力收回手机”的段落，因此删去对应的 close 落点；总结三栏与最终品牌的落点按新时间重算。
- 读表记录从“表格截图块飞回手机”改为“纯文字 chip 飞入手机并提前淡出”，落点时间不变，音色仍为纸页与短触点。
- 35–40 秒新增全幅暂停卡，但听觉沿用已有的 pause / acknowledge 落点，不新增提示音；暂停仍然是“收气”，不是警报。
- 其余 72 个落点与 26 段连续动作沿用第四版设计：纸页、折叠、抽取、触点、家人回应、双重核验、方法复用各有身份；钢琴强音附近的落点仍做有限增益补偿。

## 制作

- 音乐：v03 `music.wav` 逐字节复用，不重新演奏。
- 画面：v18 无音轨母版，视频流直接复制，不重渲染。
- 落点：75 个离散动画落点；26 段由冻结动画逐帧进度与速度驱动的连续摩擦/气流。
- 混音：b 混音（对每个动作附近测量钢琴与干声的短时 RMS，仅对被掩盖的落点做有限补偿，单项上限约 9.5 dB），保持柔和上限。
- 母带：48 kHz / 24-bit，AAC 320 kbps 立体声，-16 LUFS 量级，真峰低于 -1.5 dBTP。

## 检查

- 全片完整解码；视频流与 v18 画面母版一致；音乐预混哈希与 v03 一致。
- 75 个落点的峰值命中导出帧；26 段连续动作的起止边界帧误差为 0；AAC 解码延迟为 0。
- 干声音高与当前钢琴和弦相容；高频占比、峰值、声道平衡、响度与真峰检查。
- 数值检查不代替人耳试听；交付说明中明确“未做人耳主观听审”。
