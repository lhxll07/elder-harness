# 《为人编译》v7 初版

154 秒，原生 1920×1080，60 fps，完整画面与字幕审阅版，无音轨。

## 一次往返，而非机制章节拼接

去程：人的需求进入复杂界面，操作逐层折叠，留下人的选择。
回程：实际动作与页面事实分开核验，事实托住回答，再返回顶部悬浮窗。

v16 的通道展开、压缩回手机、中央品牌与架构闭环保留。开场 16 秒，架构从 28 秒收紧为 24 秒，全片字幕统一。源场景按连续时间重新求值，不靠抽帧加速，避免节奏改变产生重复帧或掉帧。

## 时间线

| 时间 | 动作 |
| --- | --- |
| 0—16 | v16 通道与品牌标志镜头 |
| 16—40 | 语音识别、模型规划、本机工具、页面反馈、语音打断 |
| 40—50 | “继续，挂普通内科，周四上午”；同页进入预约，揭开页面，空间标题“为人编译” |
| 50—90 | compiler-v02 原 14—54 秒的连续动作：双通道、提取、压缩、医生空位、穿入家人网页、线索返回 |
| 90—106 | 跟随“陈医生”进入医生列表；布局移动；稳定身份唯一匹配；本地校验后执行 |
| 106—118 | 当前排班页展开；按需方法折为阅读尺；表头与行内容一起读取；选项回到核对页 |
| 118—146 | compiler-v02 原 68—96 秒：本人提交、动作与结果分离、结论接受对照、事实支撑、本地及独立复核、回到悬浮窗 |
| 146—154 | 页面收拢、光色回归、中央品牌与“为人编译” |

两条核心长段保留动作、构图、运镜与前后因果，统一空间光色和字幕后重新渲染。重绑定和阅读方法只扩展原 54—68 秒较弱的执行段，不拆开“医生空位 → 家人”的视觉回应。

## 真实性

编译是视觉叙事框架。图中未来流程页面是概念流程示意，不代表系统提前观察到未来页面。目标来自老人，界面提供当前选项。家人提供线索，老人确认后续办；关键提交由本人完成。医院、医生、时间、费用是示例。

稳定身份受窗口、版本、上下文和唯一性约束；阅读尺解释按需方法对模型阅读的辅助，不是确定性表格解析器。先本地核验，再独立模型复核；模型不能覆盖本地拒绝。“预约成功”是核验对照校样，非真实误报记录。最后仍为“已提交，待医院确认”。
