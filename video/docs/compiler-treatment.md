# 《为人编译》核心叙事重写

## 不再逐章展示机制

v16 整片保留。v01 为 96 秒完整新结构样片，v02 展开核验段至 104 秒；不拼接八个旧机制章节，也不再把手机归位当作每段的标点。只有一句复诊需求、一组不断变形的界面源稿、一个未被消去的医生空位，以及最终回到手机的同一条任务。

“编译器”是影片的视觉解释框架，不是产品改名或对传统编译技术的实现声明。不修改应用、核心、服务端或真实运行数据。

## 四个记忆镜头

- **源稿长出来**：语音波形成为一句话，手机后的页面沿纵深展开；镜头绕到侧面，才看见一句需求在界面世界里有多长。
- **消去操作，留下决定**：从实际页面取出的科室和时段留在前景。其余页面逐行解体、旋离，留下医生这一项真实的信息空缺；镜头钻进空位，进入家人的网页。
- **结论试印**：提交动作先化成操作票据，医院返回另起一张事实纸。悬空的“预约成功”校样遇到“待确认”后失去支撑、转出画面。两者不相符是可见的，不用“核验通过”框代替。
- **事实托住结论**：真实状态字片从页面揭起，折成支撑结构，有据的字逐个立起来。两张校样透片先后掠过；镜头绕到斜侧，能看到结论下面仍连着来源。最后收拢成一句话，折回手机顶部悬浮窗。

## 一次编译的连续动作

| 时间 | 可见变化 | 内容依据 |
|---|---|---|
| 0—14 秒 | 语音句子 → 六页纵深源稿 | 语音 API、自然语言任务、第三方应用原界面 |
| 14—28 秒 | 像素稿与控件语义分离，再对齐同一目标 | ScreenAccessService / AndroidPhoneTools 双通道观察 |
| 28—40 秒 | 页面逐行被消去，目标信息留下；医生留空 | 对理解成本的叙事解释，不表示本地先行生成了完整固定计划 |
| 40—54 秒 | 镜头穿过空位 → 家人网页留言 → 本人核对 → 原处续办 | 亲友求助与留言，不是远程操控 |
| 54—68 秒 | 当前方法装入；页面重排；重新定位后 tool_call | 按需 load_skill、实时控件、动作前本地约束、动作后观察 |
| 68—76 秒 | 医生、时间、费用从原界面摊开；本人点按提交 | ManualActionPolicy、本人决定 |
| 75—85 秒 | 操作票据与医院回执分开；结论校样与状态纸对照；不相符的校样失去支撑 | 动作不等于业务结果；相同事实对照两种结论的可视化示意 |
| 85—96 秒 | 页面字片折成底座；有据的结论立起；两层透片复核；结果折回悬浮窗 | CompletionAudit 的本地动作与证据检查，再交独立 CloudReviewer 复核；本地拒绝不能被模型覆盖 |
| 96—104 秒 | 页面归为手机后的一层；品牌居中定格 | 压缩流程，而非压缩人的决定权 |

这些是连续动作的节拍，不作为章节标题显示。编译消去的是用户需要学习的导航过程，而不是声称程序省略了必需的实际步骤。

## 表达边界

- 医院、医生、时间、费用均为示例；家人页使用现有项目的页面素材。
- 结构树中的 e12/e13 是视觉示意编号，不能当成真实实机日志。
- 动画保留“医生未知 → 家人给线索 → 本人核对”的区别。
- 显示 `expectedEffect` 和本地检查，不把模型规划直接画成不受约束的点击。
- 不展示未实现的自动验证学习。load_skill 只解释当前可用方法的按需读取。
- 结尾状态为“已提交 · 待医院确认”，不宣称预约成功、付款成功。
- 核验段标出“对照示意”：不是宣称运行中模型确实误报，也不把拒绝后的处理画成无条件自动重试。真实实现依核验缺口决定有限重试或暂停。
- 试印、纸张支撑和透片对位解释的是事实与结论之间的依据关系，不表示应用逐字形比对、自动删词或以打印替代语义核验。
- CloudReviewer 是独立请求，只看本轮声明、操作记录、已观察的页面与近期截图；不拿执行模型的自我解释作事实。

## 渲染

原生 1920×1080、60 fps，无音轨审阅版。不重渲染 v16；已完成的 v01 保留。入口独立为 `compiler.html`，不自动打开审片页或播放器。

v02 保留 v01 前 75 秒的原帧，仅重渲染 75—104 秒，再编码完整 104 秒 MP4。复用使用独立复制或文件系统 reflink，不使用可连带改坏旧版的硬链接。QA 对前段六个采样比较；接点前一帧要求逐字节一致。其余样本只容许均值低于 0.001/255、影响低于 0.02% 像素的微小差异，并保留精确差分指标。最终复用的旧帧本身不经过重渲染。

```sh
cd video
node render/compiler-check.mjs tmp/compiler-qa
node render/compiler.mjs --version 1 --workers 2
node render/compiler.mjs --version 2 --workers 2 --reuse compiler-v01 --from 75
```

编码显式将截图的全范围转换为视频有限范围，输出 H.264 / yuv420p。最终运行逐帧连续性检查、孤立跳帧筛查和全片解码。
