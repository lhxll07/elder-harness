## 具体算法与真实边界

### 页面守卫
- `ScreenActionGuard` 首先核对 app、windowId、宽高和 revision。
- 相同 revision 可以执行；坐标工具不能跨 revision 重放。
- 直接可操作、enabled 且有稳定身份的控件，先尝试含几何的身份匹配，再尝试不含几何的稳定身份。
- 身份包含控件自身、父节点、子节点、兄弟序列；旧页与新页都须唯一匹配。
- 匿名/重复/歧义目标不能猜。重排、e12/e31、r17/r18/r19 均为算法分支示意，不是实际医院回放。
- 科室由老人明确给出，不由助手诊断选择。

### 自主与协作
- 分级自主的依据是可逆性与信息是否明确，不虚构“模型信心评分”。
- 缺信息调用 `ask_user`；关键提交、付款、验证码调用 `ask_person` 或交还本人。
- 家人页面素材由 `server/app/web.py` 和 `server/app/static/family.css` 生成，使用虚构数据。
- 接手不等于办完；手机心跳不是健康监测；提交、送达、本人已读是不同状态。
- 家人留言是给本人看的信息，不进入 Agent 任务指令，不远程点手机，不自动续办。
- 服务器通知 adapter 仅记录日志；家人端端到端实机协作尚未验证。

### 证据与复核
- 本人点按后，须明确要求继续核对，才恢复 Agent 观察。
- `actionLedger()` 只配对 assistant tool_calls 与 tool results，不能伪装成记录了本人手指动作。
- 证据账保存 app、revision、step、来源；`SELF_TYPED` 与敏感页不贡献独立事实。
- 数值事实还要核对字段和单位，不能只因数字相同就确认。
- `MechanicalFirstReviewer` 和 `CompletionAudit` 本机先行；本机拒绝不能被模型覆盖。
- 只报告“已提交，待医院确认”；COMPLETED 不等于预约成功、付款成功或外部业务终态。

### 经验复用与准入
- 常驻指令放触发规则和小目录，具体方法通过 `load_skill(name)` 进入 transcript。
- 以 `SkillCatalog.reading_tables` 的真实内置方法展示表头定位、逐条带列头读取、列头跳变后重新数列；排班表仍为示例数据。
- 书架中的扩展目录与候选方法是示意，不冒充已安装技巧，不使用虚构 token 节省数据。
- 候选经验不能当场绕过审核启用；家人示范采集学习尚未实现。
- T0：参数契约、安全策略、脱敏等静态检查。
- T1：离线反事实回放；`apps ∧ requires(page observation)`。只匹配页面观察，剥离安装应用列表和提示装饰。
- 非目标暴露率为零是准入门槛，不是动画测得成绩；requires 尚未接入运行时自动选择路径。
- T2：目标改善至少 2/3、旧任务不退化、不新增 false_done/越界、步数/token 不高于基线 1.3 倍等门禁逻辑已实现；实机回归尚未执行。
- 版本不可变，active 指针切换、旧版保留、可回退；本片候选不因动画而上线。

## 连续性与交付
- 各章起终匹配同一手机与 `[0, 0.10, 4.45]` 的摄像机锚点；回正前先收好机制舞台。
- 顶部悬浮窗采用项目真实文案：正在办、等您回答一句、已经找家人了、家人留言、等您操作、待您确认等。
- 字幕与章节时长同步；所有动画只由绝对时间决定，支持乱序调用与负的预入场时间。
- 文字及真实网页纹理压低至 bloom 阈值以下，光效留给物象高光与流线。
- 使用独占 RGBA8 FBO 采集与单 worker ANGLE Vulkan，避免读取浏览器默认显示缓冲。
- 完整渲染和编码后，逐帧差分扫描、检查章节边界、完整解码并人工查看已有帧；不打开审片页或播放器。
- 医院、医生、日期、费用和控件编号均为示意，不是真机成功证据。
