# v17 · 为人编译 · 画面定版 / 空间换章

## 交付与边界

- 保持 v16 的 196 秒时间轴、前景叙事、页面比例、镜头与跨镜继承；本轮让背景承担章节结构，不添加新的产品能力或机制。
- 原生 3840×2160、60 fps 渲染全片，Lanczos 降采样导出 1920×1080、H.264 CRF 18。
- 保留历史版本，不打开审片页。本轮仍为无音轨画面定版，之后进入声音设计，不擅自添加配音、音乐或未经确认的声音素材。
- 技术表达边界继续遵循 `fusion-v15-treatment.md`；材质与微晃沿用 `fusion-v16-treatment.md`。

## 转场与质感

- 章节边界两侧共 3.2 秒连续交接，权重和始终为 1；不突然换底、不用黑场分割。
- 所有空间共享柔和地平光带与石墨底色，以色温、光向、层距、折面和视差体现差异，不堆叠装饰。
- 编译层距、阅读光窗、方法折面和采用光区均由实际影片时间驱动，冻结源时间的插入段仍连续。
- 后半段工作区同步染色，降低其底层遮盖，让新空间可见；前景卡片、白色页面与字幕不染色。
- 标题与字幕区保留低对比净区；不增加过强泛光、亮线、镜头污渍或重景深。

## 验证

- 全时域检查背景权重、章节覆盖、连续性、有限参数及确定性。
- 预检增加每章中段与边界前后采样，并在乱序检查中重复每章中段；沿用严格阈值。
- 159.5 秒新增检查暴露报告继承画布的透明圆角累积残留；重绘前清空裁切画布，确保不同渲染顺序获得相同结果。
- 原生帧逐项对照预检，检查空白帧、孤立跳变、分辨率、完整帧序列与最终 MP4 全解码。
- 冻结源文件、背景方案、时间轴、渲染脚本、资源和验证报告，为下一轮声音设计保留稳定画面基线。
