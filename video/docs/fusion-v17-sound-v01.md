# v17 · 配乐与音效第一版

## 画面边界

本轮只做声音。使用已锁定的 `out/review/fusion-v17/fusion-v17.mp4`，196 秒、1080p60；封装时直接复制 H.264 视频流，不重渲染、不重新压缩画面、不覆盖无声版。无旁白、无真实人声、无外部音乐或音效采样。

## 声音叙事

原创程序化配乐以 96 BPM 为底层脉搏，D—E—A 三音动机贯穿全片。温暖的毡感键盘、缓慢展开的合成音垫、短拨弦和轻量低音构成主体；打击乐只在架构、操作与验证等段落推动节奏，不铺满全片。

- 开场：页面触点拉开声像，通道折叠时收拢；三音动机接住品牌，延续进入架构。
- 双通道：干、润两种短音在小幅左右声像中呼应，不做报警或科幻控制台。
- 为人编译：六页提取的起点与归位依据实际动画时钟匹配；细碎摩擦汇成短音，折叠后减少节奏密度。
- 人的决定：提问、暂停、本人核对与提交处做减法；提交只有一个点按，不用“预约成功”式庆祝音。
- 家人协作：键盘更温暖，发送与线索返回有对应落点；不暗示家人远程接管手机。
- 事实核验：本地审计为干短音，独立云端复核为同音高的圆润短音；“已提交·待医院确认”低调落定。
- 来源辨别：SELF_TYPED 对照用轻微收空，不使用错误警报。
- 方法与验证：轨迹触点重新有序化，三音动机回归；验证段增加轻脉冲，不把机制演示配成真实成绩庆功。
- 手动采用与结尾：一次明确点按体现人的采用选择，三项总结收回手机，主题动机解决并衰减，末尾留净空。

## 交付结构

默认目录：`out/review/fusion-v17-sound-v01/`。

| 文件 | 作用 |
| --- | --- |
| `fusion-v17-sound-v01.mp4` | 完整配乐 + 音效版；AAC 48 kHz 双声道 320 kbps，画面流直接复制 |
| `master-48k-24bit.wav` | 响度处理后的 48 kHz / 24-bit 无损总混音 |
| `music.wav` | 配乐独立总线，母带处理前的相对混音电平 |
| `sfx.wav` | 音效独立总线，母带处理前的相对混音电平 |
| `stems/` | 六条配乐层与两条音效层，24-bit WAV |
| `mix-premaster.wav` | 32-bit float 母带处理前总混音 |
| `cues.json` | 完整声音落点、主题音符、和声、章节、留白与随机种子 |
| `mastering.json` | 两遍响度分析及母带参数 |
| `validation.json` | 完整音画解码、视频包哈希、时长同步、响度、峰值、声道平衡和尾音检查 |
| `audio-source/` | 本次声音制作脚本与依赖快照 |
| `delivery.json` | 本轮产物与原画面校验值 |

母带目标为约 -16 LUFS，处理时真峰值目标 -2 dBTP，为 AAC 编码留余量；另检查最终 AAC 的真峰值不高于 -1 dBTP。末尾至少 0.3 秒净空。技术检查不替代实际试听；本流程不会自动打开播放器或播放音频。

## 重现

在 `video/` 目录运行：

```bash
uv venv tmp/audio-venv
uv pip install --python tmp/audio-venv/bin/python -r render/requirements-audio.txt
tmp/audio-venv/bin/python render/soundtrack.py --output out/review/NEW-SOUND-VERSION
```

生成器要求 v17 原画面 SHA-256 精确匹配。若指定目录已有完成的 `delivery.json`，会拒绝覆盖，需换新版本目录。仅母带处理阶段中断时，可以对尚未完成交付的目录使用 `--remaster`，复用已生成的完整分轨。
