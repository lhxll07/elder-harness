## 听觉记忆点

“为人编译”不靠持续轰鸣表现技术，而是让声音也经历一次压缩：分散、略不规则的界面触点，收拢成有秩序的少量节拍，最后给人的决定留出安静。全片用同一组三音动机，在不同段落中变换音色，片尾再完整回收。

- 复杂流程：细而轻的多层触点，不做刺耳通知声堆叠。
- 提取步骤：短促、清楚、带方向的归位声；避免每张卡片都重复同一段 whoosh。
- 保留决定：降低音乐密度、短暂停顿，让问题与本人确认成为声音重心。
- 核验事实：本地审计和独立复核使用不同的短音色，前后有序，不混成一个“成功”提示。
- 形成方法：把散点节拍归并为三音动机；片尾以这一动机总结，而不是突然收尾。

## 分段打点草案

| 时间 | 听觉作用 | 声音方向 |
| --- | --- | --- |
| 0—8 秒 | 从朴素需求走进流程纵深 | 极轻低频底与稀疏触点，随页面纵深拉开声像；不做压迫性心跳。 |
| 8—16 秒 | 通道收拢、品牌强调 | 层叠声逐渐合成一次干净的收束；品牌中心落点给出短而温润的标记音。 |
| 16—40 秒 | 一句话进入系统闭环 | 节奏稍清晰；语音、识别、规划、工具执行用同组音色的不同短句，避免科幻控制台噪声。 |
| 40—57 秒 | 进入办事、观察页面 | 从宽声场回到近处，点击与页面转移干净克制；双通道可做轻微左右呼应。 |
| 57—67 秒 | 多页信息提取与编排 | 六个提取触点逐步规整，收拢时轻扫频并快速衰减，与页面运动准确对齐。 |
| 67—75 秒 | 只留下需要本人决定的问题 | 音乐减法、留白；不要用提示音催促老人。 |
| 75—85 秒 | 家人接手和补充线索 | 暖一些的双音回应，发送与回到手机各有一个轻落点。 |
| 85—109 秒 | 重新定位、装入方法、阅读表格 | 简短定位音；三步阅读使用同一组递进短音，不在每个文字动画上配音效。 |
| 109—114 秒 | 本人确认与提交 | 保留一次真实感点击，随后轻微留白，让决定权清楚。 |
| 114—136 秒 | 审计、独立复核、来源辨别 | 一干一润的两个核验短音；“已提交·待医院确认”使用中性落定，不用预约成功式庆祝音。SELF_TYPED 对照以轻微抽空表现，不用警报。 |
| 136—149 秒 | 轨迹变方法、换页对齐 | 重新组合三音动机；方法成形时节奏从散到整，换版式时音色不换，以听觉强化方法保持。 |
| 149—170 秒 | 独立验证、报告与影子对照 | 更紧凑的低密度脉冲推动后半段；检查完成有清晰短落点，但不表现为真实任务已完成或真实测试成绩。 |
| 170—179 秒 | 手动采用、下一次按需装入 | 目录归位声，随后轻装入；不用自动发布式宏大上升音。 |
| 179—190 秒 | 三项总结、回到手机 | 三音动机分别对应读懂、核实、留下方法，音乐逐步展开后再收小。 |
| 190—196 秒 | 品牌与主题稳定收住 | 温和解决音，尾韵完整衰减；最后保留短净空，不截断混响。 |

## 制作与混音原则

- 先确认旁白需求，再决定音乐密度与声音留白；不把现有字幕逐字朗读当作配音稿。
- 若有旁白，先写以“需求→读懂→保留决定→事实核验→方法复用”为主线的听觉脚本，再试录核对 196 秒容量。
- 音效围绕关键因果落点，不覆盖每次运镜；声音的变化服务信息，而不是展示插件。
- 机制说明段优先保证中文语音可懂，配乐在其下自动让位；无旁白版也不靠连续高密度节拍填满空白。
- 实际素材、授权范围、音色和混音方案确认后再制作；本轮不引用来源不明的音乐，也不使用未经确认的真人声音。
- 声音制作保留独立轨道，最终版本另存，不覆盖无音轨画面母版。
