# 影棚与超采样精修

保持 214 秒时间轴、单次复诊流程、技术机制和文案不变，不拼接旧版本。

## 场景与模型

- 背景采用连续方向渐变、冷暖柔光与弧形光幕，缎面地台以距离渐隐衔接，移除旧的硬边发光背景板与高反差地面亮块。
- 环境反射加入宽柔光窗、窄条光源与暖侧光；全片降低颗粒、色散和泛光，避免以噪点制造所谓质感。
- 手机保留已有尺寸和屏幕深度契约，用 18 层轮廓重建曲面倒角中框，加入磨砂玻璃背板、独立按键、天线断点、底部接口与扬声孔。
- 后置镜组具备金属镜筒、镜片和光圈；前置镜头与听筒位于顶部留白，不遮挡正文。屏幕与外壳保持分层，避免深度冲突。
- 指触改为连续变截面食指、掌部、收拢的其余手指与腕部；指甲和关节纹理采用独立几何，皮肤用低高光暖色材质。接触点沿用已确认的提交按钮位置。

## 真正的超采样

```bash
cd video
RENDER_SCALE=2 node render/mechanism-check.mjs
npm run film -- --fps 60 --workers 1 --gpu angle-vulkan --render-scale 2
```

`--render-scale 2` 将场景、后处理缓冲、字幕纹理与最终离屏目标设为 3840×2160。每个原始 JPEG 帧保留 4K、质量 96，再用 FFmpeg Lanczos 3 一次缩至 1920×1080、H.264、BT.709 limited range、60fps，无音轨。不是放大已有 1080p，也不是仅修改视频分辨率标签。

逻辑构图与字号仍按 1920×1080 定义，避免高分辨率让字幕或章节导航变小。4K 渲染只保留少量 FXAA，主要抗锯齿由超采样完成；不启用高开销多重采样渲染目标。

每轮先完整渲染整片，再编码并验证。保留所有旧版本和原始帧，不自动打开审片页面。`film.json` 记录采集和输出尺寸，`validation.json` 检查每个原始帧的尺寸、时间连续性及成片完整解码。
